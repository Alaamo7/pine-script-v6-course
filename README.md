# Pine Script Trading Projects 📈

مستودع خاص بتطوير مؤشرات واستراتيجيات التداول على منصة TradingView باستخدام Pine Script.

## السكربتات المتاحة:
* **indicator.pine**: المؤشر الأساسي لتحديد مناطق السيولة.
* **ultimate-scalping-pro-v2.6.pine**: سكربت الاسكالبينج الاحترافي لإشارات الدخول والخروج السريعة.

_تم الإعداد والرفع باستخدام Ubuntu Linux._
