# دورة Pine Script v6 بالعربية 📈

مشروع تعليمي عملي لتعلم Pine Script v6 وبناء مؤشرات واستراتيجيات TradingView مع توثيق سلوك الإشارات، وإعادة الرسم، وافتراضات الاختبار.

> الحالة الحالية: **قيد التطوير**. الأمثلة التعليمية متاحة، لكن المشروع ليس دورة مكتملة بعد ولا تمثل نتائج الاستراتيجيات أداءً تداوليًا مضمونًا.

## مخرجات التعلم

بعد استكمال الوحدات، يُفترض أن يتمكن المتعلم من:

- فهم طريقة تنفيذ Pine Script على الشموع التاريخية واللحظية.
- التعامل مع OHLC والأنواع وبيانات `series`.
- بناء مؤشر منظم بمدخلات ورسومات وتنبيهات.
- فهم pivots وتأخر تأكيدها ومخاطر إعادة الرسم.
- تحويل قواعد تداول واضحة إلى `strategy()` قابلة للاختبار.
- قراءة نتائج Strategy Tester مع العمولة والانزلاق وحدود المحاكي.

## التشغيل

1. افتح ملفًا بامتداد `.pine`.
2. انسخ الكود إلى Pine Editor في TradingView.
3. اضغط **Add to chart**.
4. راجع المدخلات والسوق والإطار الزمني.
5. نفّذ خطوات [`TESTING.md`](TESTING.md) قبل الاعتماد على أي نتيجة أو نشرها.

## إعادة الرسم والقيود

- إشارات الاستراتيجية تعمل على الشموع المغلقة فقط.
- مستويات الدعم والمقاومة المعتمدة على pivots لا تُعرف إلا بعد شموع التأكيد اليمنى.
- مؤشر Dynamic Liquidity يستطيع العمل لحظيًا عند تعطيل تأكيد الإغلاق؛ في هذه الحالة قد تتغير النتائج أثناء الشمعة المفتوحة.
- Strategy Tester محاكي تاريخي وليس ضمانًا للتنفيذ أو الربحية في السوق الحقيقي.
